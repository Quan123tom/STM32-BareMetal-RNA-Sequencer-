# STM32-BareMetal-RNA-Sequencer-
## Bare-Metal STM32 RNA Sequencer & Pattern Matcher
A zero-overhead, bare-metal genomic sequence analyzer written entirely in ARM Cortex-M4 Assembly for the STM32F407VGT6 microcontroller. 
This project implements a hardware-optimized streaming search algorithm to find complementary RNA sequences within the SARS-CoV-2 genome, executing directly on the silicon without the use of a Hardware Abstraction Layer (HAL) or real-time operating system (RTOS).
